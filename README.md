# 🚀 Innovative AuthApp | React Native & Supabase

A high-performance, dark-themed authentication system built with **React Native (Expo)** and **Supabase**. This project features a "Rich UI" experience, automated database triggers, and robust form validation.

## ✨ Features

* **Secure Authentication:** Powered by Supabase Auth (Email/Password).
* **Automated User Profiles:** SQL triggers automatically create a `profiles` table entry upon signup.
* **Advanced Validation:** Client-side validation using **Zod** and **React Hook Form**.
* **Modern UI/UX:** Dark-mode "Innovative" design with smooth transitions and loading states.
* **Error Handling:** Custom `ErrorBoundary` component to catch and display render-time crashes gracefully.

## 🛠️ Tech Stack

* **Frontend:** React Native, Expo, React Navigation
* **Backend:** Supabase (Auth & PostgreSQL)
* **Form Management:** React Hook Form
* **Validation:** Zod
* **Styling:** StyleSheet (Custom Theme Engine)
